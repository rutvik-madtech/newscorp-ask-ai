# Build an audience from an analysis run

Applies to tier: Power User
Business unit: all
Console page: /audiences
Article type: how_to
Category: audiences

To turn an analysis run into an audience, open the run (Sidebar > **Analysis** > **Runs** > click the run's name) and click **Build an audience**. The **Create an audience** page opens with the run as its starting point. You can also select **An analysis run** under **Step 1 · Start from** on Create an audience. Its subtext names the run.

## From the run page

1. Go to Sidebar > **Analysis** > **Runs** and click the run's name in the **Run** column. The breadcrumb reads **Analysis / Run …**.
2. Check the **If you build an audience** panel. It shows **Matched only** and, separately, **With extension · not contracted**, a modelled extension (what some people call lookalikes) from a provider that is not under contract. The panel notes: "Never summed. Matched size is stated before any extension, wherever the audience goes."
3. Click **Build an audience** at the top right of the page, next to **Export**.
4. **Create an audience** opens.

## From Create an audience

1. Go to Sidebar > **Audiences** > **New audience**.
2. Under **Step 1 · Start from**, choose **An analysis run**. Its subtext names the run.

## What carries over from the run

Under **Step 1 · Start from**, a note that begins **Carried over from run …** lists what comes across:

- the run's matched people
- the attributes that indexed highly in the run
- the file's provenance

The note ends: "The advertiser’s file is not part of the audience."

**Step 2 · Membership rule** then shows a **Suggested rule from run …** box with the **AI suggestion** chip, based on the run. Expand **Why this?** for the reasons, then click **Accept into rule**, **Edit first** or **Dismiss**. You can also add your own conditions with **+ Add condition**.

## Finish the audience

Enter a **Name**, choose **Precedence when units disagree**, check **Live sizing**, then click **Save as draft** or **Send for approval**. Saving does not deliver.

## Good to know

- The advertiser's file is never part of the audience. On the run page, the **Provenance** panel shows **File** as **Dropped at teardown**.
- Run results are aggregate only. The run page says: "Aggregate only, gated by minimum population. No identifiers are returned."
- Matched and modelled sizes are never added together, on the run page or in **Live sizing**.
