# The permissible-use envelope

Applies to tier: Power User, Admin, Agency
Business unit: all
Console page: /delivery

The permissible-use envelope is the set of rules recorded with each delivery. It travels with the audience and comes back with any measurement, so everyone can see what the audience was allowed to be used for.

| Rule | Typical value | Meaning |
|---|---|---|
| Minimum population | Enforced | The delivered audience meets the minimum size |
| Source-BU obfuscation | On | The destination can't see which business units contributed |
| Source-BU approval | Granted | Every contributing business unit approved this use |
| Consent basis | US · not opted out | The consent state every person in the audience has |
| Raw PII outbound | Never | No names, emails or other raw personal data leave the CDL |
| Retention at destination | 30 days | How long the destination may keep the audience |

You can't edit the envelope on the Delivery page. It is built from the audience's gates and from the gating rules in Rules of Use. To change it, change the audience, or ask a Power User about the gating rules.
