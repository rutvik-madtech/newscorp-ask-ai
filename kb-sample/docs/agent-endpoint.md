# The agent endpoint (MCP)

Applies to tier: Power User, Admin
Business unit: all
Console page: /delivery

The agent endpoint is the machine-readable twin of the Delivery screen. Credentialed AI agents, such as an agency's buyer agent, use it to ask about audiences with the same taxonomy and permission model as the console. It runs inside the News Corp AWS account.

## What agents can do
- Ask for an audience's size, composition and delivery options.
- Submit an analysis run.
- Request an audience. The request arrives in Rules of Use as an Agent request.

The endpoint never transacts inventory, and nothing is sent until a person in the business unit approves the request.

## Managing agents
The Agent endpoint panel shows the credentialed agents, the requests in the last 7 days and the requests awaiting your approval. Admins add or revoke agent credentials in Connectors.
