# Analysis FAQ

Applies to tier: Power User
Business unit: all
Console page: /analysis
Article type: faq
Category: analysis

Answers to common questions about Sidebar > **Analysis**, where you match customer lists on the **Runs** tab and ask portfolio-wide questions on the **Portfolio** tab.

**What's the difference between the Runs and Portfolio tabs?**
**Runs** lists analysis runs, each an uploaded customer list matched against the portfolio, and you start one with **New analysis**. **Portfolio** gives "Portfolio-wide answers with no advertiser file involved." There you can ask a portfolio question and read **What the portfolio can reach** and **Where two units meet**.

**Where is my uploaded file kept?**
Inside the News Corp account, for the life of the run. The upload dialog says: "Matching runs inside the News Corp account. The file is not copied out and is dropped at teardown." A run's **Provenance** panel shows **File** as **Dropped at teardown**.

**Why isn't my conversion value imported?**
Value data is out of scope. When your file has a value column, the **Upload a file** dialog shows a warning that names the column and says it will not be imported. Attribution stays with the advertiser.

**Why is Region declared required?**
Its helper text reads **Required · drives the consent regime**. The region you declare sets the consent rules that apply to the run.

**Do run figures update?**
No. A run page's subtitle ends **complete · all figures as of completion**, so its figures stay as they were when the run finished.

**Why is there no overlap percentage?**
"No overlap percentage is shown until the analysis is verified against the spine." Until then, overlap shows **Not verified**. On the Portfolio tab, a pair whose **Minimum size** is **Below** shows a dash instead.

**Can agencies run analyses?**
Agency users don't see Analysis in the console. Agency agents submit runs through a credentialed connection, and those runs appear on the **Runs** tab with the **Agent** chip in the **Source** column. The run's **Provenance** panel shows the **Channel**, such as **Credentialed · MCP endpoint**.

**Where do I find a question I saved?**
**Save the question** keeps the question's wording and term mapping, and no people. The **Portfolio** tab shows the **Ask a portfolio question** card, **What the portfolio can reach** and **Where two units meet**.

**Is a run or a portfolio question an audience?**
No. Click **Build an audience** on a run. For a portfolio question, click **Start** next to **Turn it into an audience** on the screen that opens from **What happens next** on **The finding**, and each contributing unit is asked first.
