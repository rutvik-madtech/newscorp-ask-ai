# Status chips and markers across the console

Applies to tier: Power User
Business unit: all
Console page: /
Article type: reference
Category: concepts

The console uses one shared set of chips, tiles and markers across its pages, including Overview, Audiences, Analysis, Rules of Use and Delivery. Use this table to look up what a chip, colour or marker means and where you see it.

| Chip or marker | Looks like | Meaning | Where you see it |
|---|---|---|---|
| **Live** | Green chip | Active or live. | Shared status chip used across the console. |
| **Active** | Green chip | The audience definition is live. | **Status** column on Audiences. |
| **Pending you** | Amber chip | Waiting for your decision. | Shared status chip, for example in the **Status** column on Audiences. |
| **Failed** | Red chip | The item failed, such as a delivery or an analysis run. | **Status** column on Delivery; **Failed · …** with the reason on Analysis > Runs. |
| **Cross-BU** | Blue chip | Involves more than one business unit. | **Type** column on Audiences. |
| **Suppressed** | Lock icon with grey text | Below the minimum population. No value is shown, and it can't be revealed. | Composition rows on an analysis run, **What the portfolio can reach** on Analysis > Portfolio, breakdown cells in a portfolio question finding. |
| **Not verified** | Grey chip | An overlap that has not been verified against the spine. No overlap percentage is shown. | **Overlap** column on Analysis > Portfolio, and the overlap row on a portfolio question result. |
| **Matched · deterministic** | Solid tile | The matched audience: people found by deterministic matching. | Size cards in an audience's detail panel, **Live sizing** on Create an audience, seed audience results. |
| **Modelled · separate audience** | Dashed, striped tile with a plus sign | A modelled extension, kept as its own audience and never added to the matched figure. | Beside the matched tile in an audience's detail panel and in **Live sizing**. |
| Gate row | A check on the left, its result chip on the right | The result of a check the audience or request must pass. | **Gates** in an audience's detail panel, **Live sizing**, seed audiences and approval dialogs. |
| **Passed** | Green chip in a gate row | The check passed. | Gate rows such as **Minimum population**. |
| **Required** | Amber chip in a gate row | An approval is still needed. | Approval gates named after a business unit, such as **Realtor.com approval**. |
| **AI suggestion** | Purple dashed tag | Content proposed by AI. It comes with **Accept**, **Edit**, **Dismiss** and **Why this?**. | Next to the suggested content. |
| **AI unavailable** | Grey chip | The AI feature can't be used right now. | Shared console pattern. |
| Loading | Grey placeholder bars | The page or panel is still loading its content. | Any page or panel while it loads. |
| Decline buttons | Red button | A negative action. | The **Decline request** button in the **Decline request** dialog in Rules of Use. |

## Good to know

- Gate rows can show other results too, such as **On**, **Never**, **Pending** and **Given**. See Audience gates for each one.
